# Neon agent guide

This is the macOS platform repo of Neon, a personal fork of Helium. The rules, layout and plan
live in the core repo, checked out here as the `helium-chromium` submodule: read
`helium-chromium/AGENTS.md` and `helium-chromium/neon/PLAN.md` first. If the submodule is not
checked out, the same files are in `~/projects/neon`.

Never open issues, pull requests or comments on any `imputnet` repository, and never push to one.
